# Roadmap

## Phase 1: Local MVP

- Resume and JD upload
- Text extraction
- Basic and hybrid RAG
- Interview question generation
- Manual answer submission
- Source-grounded scoring report

## Phase 2: Interview Engine

- Live webcam recording
- Recorded video upload
- Audio extraction and transcription
- Follow-up questions based on previous answers
- Session memory

## Phase 3: Advanced RAG

- Sentence-transformers embeddings
- Cross-encoder reranking
- Parent-child retrieval
- Metadata filters
- Multi-query retrieval
- Long-term vector memory

## Phase 4: Agentic ADK Layer

- Interviewer agent
- Resume analyst agent
- Evaluator agent
- Feedback coach agent
- Tool-driven retrieval and scoring

## Phase 5: Multimodal Coaching

- Speaking pace
- Filler words
- Answer structure
- Transcript confidence
- Optional presentation metrics

Avoid emotion, personality, demographic, health, or identity inference from video. Keep the feedback about coachable interview behavior.

## Phase 6: Production

- Auth
- Persistent PostgreSQL database
- Qdrant or Weaviate
- Neo4j or FalkorDB
- Background workers
- Evaluation datasets
- Deployment profiles
